# NutriFlow

NutriFlow is an AI-powered food demand forecasting and surplus redistribution platform.

## Technology Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python
- Django

### Machine Learning
- Python
- Pandas
- Scikit-learn
- Joblib

### Database
- SQLite during development

## Main Features

- Meal demand forecasting
- Preparation quantity recommendations
- Food surplus tracking
- Food safety verification
- Recipient matching
- Pickup management
- Food, cost and carbon savings
